# E-portfolio – Amelie Barré

Sidan ligger på **https://ameliebarrebarre.github.io**

## Så ändrar du sidan

1. Öppna `index.html` här på GitHub och tryck på pennan (✏️ Edit).
2. Ändra texten och tryck på **Commit changes**.
3. Efter ungefär en minut syns ändringen på sidan.

- **Text och innehåll** finns i `index.html`. Där ligger en mall för nya sektioner (t.ex. *Projets*, *Compétences*, *Contact*) som du kan kopiera.
- **Färger och utseende** finns i `style.css`. Färgerna står högst upp i filen.
- **Bilder och PDF:er** laddar du upp med *Add file → Upload files*. Sedan länkar du till dem, till exempel `<img src="bild.jpg">` eller `<a href="cv.pdf">CV</a>`.
